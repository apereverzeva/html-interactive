# Work Or Personal Embed

This repository is prepared for GitHub Pages.

## Publish

1. Open this folder in GitHub Desktop.
2. Click **Publish repository**.
3. Make sure **Keep this code private** is unchecked.
4. Publish to GitHub.
5. In GitHub, open **Settings** -> **Pages**.
6. Set **Source** to **Deploy from a branch**.
7. Select branch `main` and folder `/root`, then save.

## Embed

After GitHub Pages gives you a URL, use:

```html
<iframe
  src="https://USERNAME.github.io/REPOSITORY/"
  width="100%"
  height="700"
  style="border:0;"
></iframe>
```
